# Tour-Studio

Werkzeug zum Zusammenstellen von Reiseführer-GPX-Dateien für die iPhone-App „GPX-Reiseführer“.

**Öffnen:** https://gunnarfrei.github.io/tour-studio/

- GPX-Route laden (z. B. aus bikerouter.de)
- Sehenswürdigkeiten entlang der Route suchen (OpenStreetMap, Ersatzquelle Wikipedia)
- Auswahl, Texte bearbeiten, nahe Orte zusammenfassen, Zeitplan prüfen
- Reiseführer-GPX speichern

Alle Daten bleiben im Browser; es werden keine Routen hochgeladen außer den Suchanfragen an
OpenStreetMap/Wikipedia.
